Run notes

  • Limited statistics. n = 3 runs per cell is small — treat cells as mean ± std, not point estimates.
  • Budget consumption. Agents rarely call /complete, so most runs consume the full 1200s budget; elapsed time is a weak signal of effort.
  • Unaided scores. All figures are for intel=none; performance with authored intel is not represented here.
  • Single judge. The LLM judge is one model (sonnet-4-5), kept outside the contestant pool to avoid self-grading bias — but still a single judge.
  • Inference-profile variance. Bedrock inference-profile routing can introduce run-to-run variance independent of model capability.
  • Cost figures. Token and cost numbers are provider-billed and may differ from harness-side accounting.
